KYAW ZINN THANT & SOE MYAT THU — WEDDING WEBSITE
=================================================

FILES
- index.html : website
- photos/    : put couple photos here (currently empty)
- music.mp3  : add your own music file here if you want music

HOW TO UPLOAD TO YOUR EXISTING GITHUB PAGES REPOSITORY
1. Download and unzip this ZIP on your computer.
2. Open your existing GitHub repository:
   https://github.com/khantzinnthant-byte/Kyawzinnthant-Soemyatthu-Wedding
3. Open the repository and choose Add file > Upload files.
4. Upload index.html and the photos folder (after adding photos), plus music.mp3 if using music.
5. If GitHub asks to replace the existing index.html, confirm the replacement.
6. Scroll down and click Commit changes.
7. Wait a minute or two, then open your live site and refresh.

ADDING PHOTOS
1. Copy your chosen couple photos into the photos folder.
2. Name them exactly: couple1.jpg, couple2.jpg, couple3.jpg
   (If your photos are PNG, either keep the .png extension and update the HTML, or convert them to JPG.)
3. In index.html, replace each placeholder block inside the gallery with:
   <img src="photos/couple1.jpg" alt="Kyaw Zinn Thant and Soe Myat Thu">
   Repeat with couple2.jpg and couple3.jpg.

MUSIC
- Put an MP3 file named music.mp3 in the same folder as index.html.
- Use music you have permission to share.
- Phones usually require visitors to tap Play Music before audio starts.

IMPORTANT TO EDIT BEFORE THE WEDDING
- The map button currently points to general Samut Sakhon. Replace it with the exact venue's Google Maps link once you know the venue.
- Countdown is set to 11:00 AM Thailand time on 8 November 2026. Change the time in the JavaScript if needed.
- RSVP/phone contact has not been added yet.
